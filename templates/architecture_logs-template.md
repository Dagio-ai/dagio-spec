# Architecture Change Log

> <small>[Architecture Overview](./architecture_overview.md) > <strong>Architecture Change Log</strong></small>

Use this file to track every architecture model revision.

## Getting Started

- Create a new section for each `model_version`.
- Capture the timestamp, summary of changes, impacted views, and follow-up actions.
- Reference the corresponding entries in `architecture.json` for checksums and paths.

## Example Entry

```
## v1.0.1 - 2024-05-01T12:34:56Z

- Added container `web-app` and component `billing-service`.
- Updated `c2_containers/web-app/container_diagram.md`.
- Follow-up: document data retention policy for invoices (review security/privacy implications).
```
